## SWOT Analysis

The first question immediately is, what is SWOT?
SWOT stands for - Strengths, Weaknesses, Opportunities, and Threats. SWOT analysis can help show the priorities for the upcoming milestones and focus on the important areas that are perfrom well, need imrpovement and major priority to reveiw. SWOT is a well-known strategy tool using in the planning process:

STRENGTHS: Positive factors that gives a competitive advantage
WEAKNESSES: Factors may lack comparison to competitors
OPPOTUNITIES: Positive factos can leverages to increase success
THREATS: Negative factors that prevent from reaching goals

SWOT analysis gives your team the blueprint and helps it make easier to base decisions strategically without doubts. The benefits of SWOT are:

1. Improves strategic planning - build a game plant that is effective and having the important factors at hand and its impacts

2. Informs decisions - seeing all sides of the picture and weighing out what options would be most benefical and overall better and the purpose of said decisions.

3. Enhances adaptability - knowing that is trending and staying competitve with processes, user wants/needs and global conditions.

4. Offers competitive advantage - seeng the strengthe that make you stand out from your competitors.

From using SWOT on Three Little Ladies Bakery, it can. help identify areas where the project is performing well, ares that need imrprovements and seeing the external. factors that can impact further development.

## OWASP Web App Security Risks

The OWASP (Open Web Application Security Project) is a global non-profit organization that helps to improve the constant presenc of software security. The tope 10 Security Risks are as follows:

1. ## Broken Access Control -
   when web app fails to correctly restrict user access to sensitive data and its functionality.
2. ## Cryptographic Failures -
   failure to use cryptography when needed or misusing crypographic components that impacts effectivness and security.
3. ## Injection -
   web app uses languages that interwine user-provided data and its not properly validates or filtered.
4. ## Insecure Design -
   design failures in an app's structure and security controls are not included.
5. ## Security Misconfiguration -
   misconfigurated app
6. ## Vulnerable & Outdated Components -
   3rd aprty components and plugins aren't kept up-to-date and if used can hold potential threats inside the software.
7. ## Identification & Authenticatioon Failures -
   failing to validate a user's indentity
8. ## Software & Data Integrity Failures -
   when using and trusting a 3rd party's code or data without proper verification and validation of its security.
9. ## Security Logging and Monitoring Failures -
   inadequate and sensitive data inside log files.
10. ## Server-side Request Forgery (SSRF) -
    web app fecths remotes resources from a URL that's given by a users without verifiying the URL is safe.

## CodeQL

Created by GitHub, it scans and reviews the source code and helps find potential threats, vulnerabilities and issues within your code. Benefits of using CodeQL are as follows below:

- automated vulnerabilities detected
- integrates with GitHub repo(s)
- checks PR security
- supports multiple programming languages
- continues monitoring during development phase

Alternate Scanning Tool:

- SonarQube : performs static code analysis
- Snyx : intergrates directly into development workflows and CI/ID pipelines
- ESLint Security Plugins : can identify unsafe coding patterns while in the development environment.
- OWASP Dependency-Check: reveiws project dependencies and finds publicly known vulnerabilities.

## Creativity and Innovation - Independent Study

For this week's independent study, I chose to view the two topics: Fair Use and Reading Accessibility from Electronic Frontier Foundation link [https://www.eff.org/issues/innovation]

- Fair Use:
  Fair Use is a legal instruction that allows limited use of copyrighted material without requiring permission from the copyright holder under certain situations. It supports creativity, education, commentary, criticism and innovation by allowing crators and developrs to build upon existing works in specific situations.

  KET NOTES:
  - Encourages innovation by allowing limited uses of copyrighted content.
  - Educational, transformative and non-commercial uses are more to qualify as Fair Use.
  - Is evaluated by a case basis using points as: purpose, nature, amount used and market impact.
  - Developers and content creators should undersand copyright limitations when incorporating media into websites and apps.

For Three Litte Ladies Bakery website, this research establishes the importance of using original images, content and branding whenever possible. If 3rd party resources are used, proper licensing and copyright considerations should be reviewed to ensure compliance and avoid legal fees.

- Reading Accessibility:
  Reading Accessibility focsues on ensuring digital content is accessible and understandable for users with varying abilities, including those with visual impairments, learning disabilities and/or other accessibility needs.

  KET NOTES:
  - Websites should be designed to support screen readers and assistive technologies.
  - Clear navigation and readable content that imrpoves usability for all users.
  - Proper color contrast, heading structure and alternate text improves accessibility.
  - Accessibility pushes inclusion and expands the audience that can effectively use a website.

  As I am continuing the development process of Three Little Ladies Bakery website, I plan to strengthen accessbility by:
  1.  Add descriptive alternate text to images.
  2.  Use semantive HTML elements.
  3.  Maintain appropriate color contrast.
  4.  Creating clear navigation structures.
  5.  Testing responsive layouts across different devices.

Overall, researching these two topics helped me have a better understanding of how legality and accessibility considerations affect modern web development. I learned that innovation involves more than creating new features - the requirement of respecting intellectual property rights and designing experiences that are accessible to diversed audiences. Applying these practices and principles to my project will help make the website that more professional, ethical and user-focused.
