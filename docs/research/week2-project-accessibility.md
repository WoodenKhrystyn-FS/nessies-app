## What is WCAG?

Web Content Accessibility Guidelines - a set of technical guides or advice that help make the web accessible to people with disabilities. An organization that complys with ADA (Americans with Disabilities Act) follows WCAG standards and it follows these four main principles:

    1. Perceivable: Information taken in by only one of their senses to beable to understand content.

    Ex. - Addiing alternative text to images, legiable fonts and text sizes and color contrast

    2. Operable: Users must able to interact with all web elements.

    Ex. - Clear navigation menus, keyboard navigation support and access to forms and buttons.

    3. Understandable: Users having the ability to understand the web content and functionality information.

    Ex. - Web pages with clear titles/headings, consistent and simple content

    4. Robust: Website effectively communicates information to ALL users.

    Ex. - Semantic HTML, heading structure

---

## Accessibility Improvements for Three Little Ladies Bakery

### Alternative Text for Images

The website will include products and brand images. Each image will have descriptive alternate text so screen readers can communicate image information to users.

### Semantive HTML Structure

Pages will use semantic HTML elements as in:

    - headers
    - nav
    - main
    - section
    - footer

These elements will help improve navigation for screen readers and overall accessibility.

### Color Contrast

The text will sustain contrast against the background colors to help readability for users with visual impairments.

### Accessible Navigation

Navigations links will be easy to find and accessible using keyboard controls.

### Form Accessibility

Any contact form will include the proper associated links and clear instructions.
