## Overview

The two topics from the Electronic Frontier Foundation related to Creativity and Innovation are Fair Use and Reading Accessibility. I chose these two topics to have a better understanding how copyright laws and accessibility considerations can impact web development projects.

These topics are important because developers must balance creativity, legal compliance and accessibility when creating digital experience for users.

---

## Fair Use

# What is Fair Use?

Fair use is legal instruction that allows limited use of copyrighted material without obtaining permission from the copyright owner. Fair use is commonly applied for purposes such as education, commentary, criticism, news reporting and research.

# Key Factors

- Not all online content is free to use
- Images, text, videos and graphics may be protected by copyright
- Developers should obtain permission or use properly licensed content whenever possible.
- Fair Use is evaluated on a case-by-case basis.

# Apply to Project

For the Three Little Ladies Bakery website, it's important to ensures all images, logos and written content are either original, properly licensed or used with permission.

As the project grows, I plan to continue using original assets and properly credit 3rd-party resources when necessary.

---

## Reading Accessibility

# What is Reading Accessibility?

Reading accessibility focuses on ensuring that digital content can be easily understood and accessed by users with different abilities, learning styles and assistive. technologies.

# Key Factors

- Content should be clear and easy to read
- Websites should support screen readers
- Proper heading structure improve navigation
- Color contrast should support readibility
- Alternate text should be provided for images

# Apply to Project

The website can benefit from accessibility improvements including:

- Meaningful image alternate text
- Improved heading ranking
- Improved color contrast
- Descriptive button labels
- Responsive layouts for multiple devices

The improvements can help create a better user experience for all visitors.
