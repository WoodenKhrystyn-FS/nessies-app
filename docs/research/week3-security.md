### Week 3 Research - Security & Code Scanning

## Project

Three Little Ladies Bakery Website

## Research Topics:

GitHub CodeQL, Snyx, SonarQube, Dependabot - Code Scanning, App Security and Dependency Management

---

## Overview

This week reserach conducted was over code scanning and security tools that help developers find vulnerabilities, coding mistakes, exposed secrets and dependency risks before software is deployed. Security is an important part of the software development lifecycle because vulnerabilities can lead to data breaches, application downtime and poor user experiences.

As the Three Little Ladies Bakery Website continues to evolve, implementing security best practices early can help reduce future risks and improve the overall quality of the application.

---

## GitHub CodeQL

# What is GitHub CodeQL?

CodeQL is a language and tool for code analysis that includes code scanning features. It automatically analyzes sourc code and identifies potentila security vulnerabilities, coding errors and quality issues.

# Benefits

- Automated security analysis
- Integrates directly with GitHub Actions
- Identifies common vulnerablities
- Supports multiple programming languages
- Helps maintain secure codebases

# Apply to Project

As development continues, CodeQL could be integrated into the repo to automatically scan React and JavaScript code for security concerns before merging pull requests.

---

## Alternate Security Tools

# Snyk

Snyk focuses on identifying vulnerabilities in project dependencies and open-source packages.

# Benefits

- Dependency vulnerability scanning
- Continuous monitoring
- PR integration
- Security recommendations

# Apply to Project

Since the bakery website uses React and npm packages, Snyk could help identify vulnerable dependencies before deployment.

---

## SonarQube

SonarQube is a code quality and security analysis platform.

# Benefits

- Static code analysis
- Code quality metrics
- Security issue detection
- Technical debt tracking

# Apply to Project

SonarQube could help improve code maintainability while also identifying potential security weaknesses.

---

## Dependabot

Dependabot is a GitHub tool that automatically monitors project dependencies and creates pull requests when updates are available.

# Benefits

- Automatic dependency updates
- Vulnerability alerts
- GitHub integration
- Easy maintenance

# Apply to Project

Dependabot could help keep project packages updated and reduce security risks caused by outdated dependencies.

---

## Developmental Impacts

This reserach shows the importance of integrating security throughout the development process rather than waiting until deployment. Security tools can help automate vulnerability detection, improve code quality and reduce maintenance efforts.

Future developments for Three Little Ladies Bakery website:

1. Enable GitHub CodeQL scanning
2. Configuring Dependabot updates
3. Regular dependency reviews
4. Security testing before deployment
5. Following secure coding practices

---

## Reflection

Following this research has helped with a better understanding how modern development teams use automated security tools to identify vulnerabilities and improve softwre quality. I learned that security is not a one-time task but a continuous process that should be included throughout development. As I continue building the Three Little Ladies Bakery website, I plan to apply these concepts by monitoring dependencies, reviewing cod quality and exploring GitHub security features.
